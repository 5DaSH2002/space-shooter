# ⚡ Nova Strike — Space Shooter

**Version: v2**

لعبة سبيس شوتر (تصويب فضائي) بتشتغل في المتصفح، تصميمها متجاوب مع الموبايل، من تطوير **Mohamed Hassan**.

## عن اللعبة

انت طيّار مركبة فضائية، مهمتك تدمّر أعداء بيهجموا عليك وتوصل لآخر كل قطاع فضائي (Sector) عشان تواجه بوس. عندك **25 قطاع**، كل واحد له بوس مختلف بشكل وحركة وهجوم خاص بيه، وكل ما تتقدم بتزيد الصعوبة. اللعبة بتحفظ تقدمك (الكوينز، أعلى نتيجة، السفينة اللي مختارها، والترقيات) على جهازك تلقائيًا حتى لو قفلت المتصفح.

## الجديد في v2

- تبديل اللغة **عربي / إنجليزي**
- 6 أنواع أعداء بأشكال وألوان وحركة وطلقات مختلفة
- باور-أبس سلاح بأشكال مميزة (مش بس ألوان):
  - ليزر مزدوج، شعاع الموت، طلقات ثلج، نوفا، صواريخ…
- كل نوع طلق له صوت خاص
- سلاح الباور-أب بيستبدل السلاح الأساسي مؤقتًا ويرجع بعده
- بوسز أذكى في الحركة والتتبع
- زرار FIRE شفاف أكتر
- إصلاحات استقرار وأخطاء
- خيار مكان الجويستيك شمال / يمين (حسب إيد اللاعب)
- ترقية سرعة الطيارة تتشترى بالكوينز من المتجر
- أيقونات الترقيات في الشوب مميزة + أشكال سفن متنوعة في المعاينة

## الملفات

```
index.html   → هيكل الصفحة (HTML)
style.css    → التنسيق والألوان والانميشن
script.js    → منطق اللعبة
README.md    → هذا الملف
```

الثلاث ملفات الأساسية لازم تفضل مع بعض في نفس المجلد.

### تشغيل اللعبة
افتح `index.html` في أي متصفح (تفضيليًا Chrome على موبايل Android لوضع ملء الشاشة الأفقي).

## التحكم

| الفعل | لوحة المفاتيح | الموبايل |
|---|---|---|
| الحركة الحرة | `A`/`D`/`W`/`S` أو الأسهم | جويستيك افتراضي |
| إطلاق النار | Space (اضغط مطوّل) | زرار 🔥 FIRE |
| إيقاف مؤقت | `P` | زرار Pause |
| تغيير اللغة | — | زرار 🌐 |

## الباور-أبس

| الشكل | التأثير |
|---|---|
| ⚡ صاعقة صفرا | إطلاق سريع |
| 💧 سداسي سماوي | حاجز +5 |
| 🌀 كرة شوك | ضرر أعلى |
| ❄ 3 ماسات | ضربة ثلاثية |
| 🛸 سفينة خضرا | وينجمان |
| 🚀 صاروخ برتقالي | رشقة صواريخ |
| 🟡 كبسولتين صفرا | ليزر مزدوج |
| 🔴 بلورة حمرا | شعاع الموت (اضغط FIRE) |
| 🔵 كريستال تلج | طلقات ثلج تخترق |
| 🟢 نجمة خضرا | انفجار نوفا مساحي |
